# CrappierGPT
An experimental LLM pretrained using tokenizations uniformly randomly selected from all possible tokenizations as source, with first character of min-length continuation from after source as target. If there are multiple valid targets, the longest serves as the tiebreaker. Run as python wrapper.py \[documents per fetch cycle\] \[number of cpu cores\] \[size of internal buffer\] \[context window length \(please use 1024 since the wrapper is hardcoded around that as context length\)\] after moving all the files from inside training data out. The wrapper will start outputting text after saving.
