# CrappierGPT
An experimental LLM pretrained using tokenizations uniformly randomly selected from all possible tokenizations as source, with first character of min-length continuation from after source as target. If there are multiple valid targets, the longest serves as the tiebreaker. Please find the missing file [here](https://huggingface.co/datasets/segyges/OpenWebText2/resolve/main/openwebtext2.jsonl.zst.tar).
